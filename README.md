# Food-Tracker

- First, Create an account username
- Then, Create a food item of your choice
- Next, Enter your food into the Food log

# Full Stack Application

- Front End Hosted on [Netlify](https://food-tracker-mern.netlify.app/)
- Back End hosted on Heroku

- MongoDB
- Express
- ReactJS
- Node
- Bootstrap
